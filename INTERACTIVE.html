Lesson 1 Geometric Sequences & Series

Visualise terms, common ratio, and sums interactively

GeoGebra

Geometric Sequence Explorer

Drag sliders to change the first term and common ratio. Watch the sequence points and the curve update in real time.

How to use:
  1. Adjust a (first term) and r (common ratio) with the sliders.
  2. Observe how the plotted points move when |r| > 1 (growth) or |r| < 1 (decay).
  3. Try r = 2, r = 0.5, and r = -1 to compare patterns.

Graph Geometric Sequences

Use Desmos to plot an = a1 rn-1 and explore how the graph changes with different values of a1 and r.

Try this:

  2. Change r to 0.5 and see the sequence decrease.
  3. Use a table to list the first 8 terms of your sequence.

Lesson 2 Population Growth

Model and graph exponential growth interactively

Desmos

Population Growth Graph

Graph P(n) = P0 (1 + r)n. Change the initial population and growth rate to see how the curve steepens or flattens.

Suggested setup:
  1. Define P_0 = 1000 and r = 0.05 (5% growth).
  2. Plot y = P_0 (1 + r)^x for x = 0.
  3. Add a table of values for years 0 to 10 and compare with the curve.
  4. Increase r to 0.10 and observe faster growth.
Open Desmos
GeoGebra

Exponential Growth Activity

Explore exponential (geometric) growth with an interactive GeoGebra worksheet. Adjust parameters and see population change over time.

Focus: Treat the common ratio as (1 + growth rate). For 4% growth, use r = 1.04 and compare the discrete points with a continuous exponential curve.

Lesson 3 Depreciation

Visualise reducing-balance decay over time

Desmos

Depreciation (Decay) Graph

Graph V(n) = V0 (1 - r)n to see how book value falls. Compare different depreciation rates side by side.

Suggested setup:
  1. Set V_0 = 20000 and r = 0.15 (15% depreciation).
  2. Plot y = V_0 (1 - r)^x for x = 0.
  3. Add a second curve with r = 0.10 and compare how quickly value falls.
  4. Use a table to list book values for years 0 8.
Open Desmos
GeoGebra

Geometric Decay Activity

Use GeoGebra to model geometric decay. Change the common ratio to values between 0 and 1 and watch the sequence decrease.

Focus: Set the common ratio to 0.85 (15% depreciation) or 0.90 (10% depreciation). Compare with growth models from Lesson 2.
